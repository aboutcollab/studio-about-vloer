# Studio About vloer

A 3D model of the interior of Studio About's new hall in Amsterdam: the deck with the studios, the community
kitchen, the sky ceiling, the cabinets and the lights. Open it at **https://aboutcollab.github.io/studio-about-vloer/**.

Drag to turn, scroll to zoom. The buttons switch the levels, the views, the bar layout, the front wall and the lights.

This page is built from a private design folder; it changes there and is copied here.
